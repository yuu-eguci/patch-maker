## ベースライン (2026-10-08 調査)

- 構成は `PatchMaker.py` 1 ファイルのみです。依存ライブラリはありません。
- ローカルの Python 3.9.6 で、 README どおりの使い方 (冒頭の `targetpaths` を書き換えて実行) で動作しました。
- テスト、 lint 、 CI 、 Docker はありません。
- 確認した問題点です。
    - `../secret.txt` を指定すると、パッチディレクトリの外 (スクリプトと同じディレクトリ) へコピーされます。既存ファイルを上書きする可能性があります。
    - 行は `\n` だけで分割されます。行末の空白や `\r` (CRLF) が残り、存在するファイルが「見つからない」扱いになります。
    - 対象パスは `set()` を通るため、コピー順が不定です。ディレクトリ `d` と `d/f.txt` を同時に指定すると、順序次第で `FileExistsError` になります。
    - パッチ名 `PATCHNAME` はモジュール読み込み時に決まります。
    - 絶対パスは `<パッチ名>//絶対パス` となり、偶然パッチ内に収まっています。
